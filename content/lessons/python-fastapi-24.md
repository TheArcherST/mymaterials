# Домашнее задание 

Установите на своём домашнем компьютере Docker Desktop, например по [этой статье](https://selectel.ru/blog/tutorials/docker-desktop-windows/).

Если возникли технические трудности, опишите в результате выполнения домашнего задания на каком моменте вы застряли, и что пытались сделать чтобы решить проблему.

Напишите Dockerfile такого содержания

```Dockerfile
FROM ubuntu
```

И сделайте образ на основе этого Dockerfile.  Для этого в директории с вашим Dockerfile выполните команду

```bash
docker build --tag=some-image-name .
```

И найдите его в списке образов:

```bash
docker image list
```

Затем с помощью команд `docker container create` и `docker container start` запустите какую-то любую программу, которая есть в вашем image. Например, `ps` или `ls`.  Если вы запустите одну из них, их выполнение прекратиться достаточно быстро, поэтому контейнер остановиться почти сразу после запуска.  Посмотрите что у вас по итогу будет в `docker container list -a` и укажите это в результате выполнения домашнего задания.  Попробуйте так же самостоятельно найти в Интернете, что именно значит цифра в скобках, которудю вы скорее всего увидите как часть статуса контейнера, и добавьте к выполненному домашнему заданию результаты поисков.

Синтаксис нужных команд тоже можете гуглить.  Например, можно загуглить как именно надо вызывать команду `docker container create`, чтобы вспомнить, что после самой команды надо указывать название образа, затем команду контейнера, например так: `docker container create some-image-name ls`.
