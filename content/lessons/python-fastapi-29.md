# Домашнее задание

Запустите свой проект на компьютере с использованием Docker и NGINX.

Поскольку локально не получится настроить HTTPS так, как мы делали это на занятии, **не используйте HTTPS**. Настройте взаимодействие по обычному HTTP следующим образом:

* Измените конфигурацию NGINX и `compose.yaml` так, чтобы запрос, приходящий на порт `8080` вашего компьютера (или другой порт на ваш выбор), перенаправлялся в NGINX-контейнер на порт `80`. Например:

  ```yaml
  ports:
    - "8080:80"
  ```

* В конфигурации NGINX объявите сервер, работающий на порту `80`.

  Укажите:

  ```nginx
  listen 80 default_server;
  server_name _;
  ```

  `server_name _;` нужен для того, чтобы не фильтровать запросы по значению HTTP-заголовка `Host`.

  `default_server` нужен для того, чтобы этот сервер использовался NGINX по умолчанию для порта `80`. В противном случае NGINX может выбрать сервер из файла `/etc/nginx/conf.d/default.conf`.

* SSL-сертификаты в этой конфигурации указывать не нужно. NGINX должен принимать обычные HTTP-запросы.

В качестве результата выполнения домашнего задания приложите вывод команды:

```bash
docker compose logs gateway
```

где `gateway` — название Compose-сервиса, с помощью которого запускается NGINX.

В логах должно быть видно:
* что NGINX успешно сконфигурировался и запустился;
* что NGINX получил HTTP-запросы.

Чтобы запрос появился в логах, достаточно открыть в браузере:

```text
http://127.0.0.1:8080
```

или другой порт, который вы выбрали.
